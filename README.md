# L.U.M.I.A. Motion Lab

Motor visual y de animaciones de **L.U.M.I.A.**, desarrollado independientemente del asistente original.

**Estado:** repositorio inicializado para conservar arquitectura, código y trazabilidad de L.U.M.I.A. Motion. Baseline de referencia: **v0.8.5 R8 — Natural Conversation Motion**.

## Visión

- **Primero:** integrar la cabeza VRM animada dentro del portal luminoso del cerebro original, con ojos, boca, expresiones y voz sincronizadas.
- **Después:** habilitar el cuerpo digital completo con movimientos, caminatas, compositor de bailes bajo demanda y futura interacción espacial.

El cerebro original está en [orbi-jarvis-agent-lab](https://github.com/ingeniusvictor/orbi-jarvis-agent-lab). El proyecto de apartamento 3D es independiente.

## Seguridad y recursos 3D

Este repositorio es **público**. No publicar directamente los FBX descargados de Mixamo ni el VRM aprobado sin verificar antes las autorizaciones de redistribución. Mantener el paquete R8 original y los recursos locales como respaldo. El compositor debe importar bailes de 1 a 3 clips solamente cuando se necesiten; los 34 archivos de breakdance no forman parte del motor esencial.

## Continuidad

Consultar `docs/lumia-convergence/` en la rama de documentación. La primera integración es **Portal Head**, no una sustitución del cerebro original. Toda implementación debe hacerse en una rama y revisarse antes de mezclar con `main`.

> Nota: la creación inicial de este README se realizó para abrir `main` porque el repositorio estaba vacío; no modifica el código de ningún otro proyecto.
